# Legacy Inertia Controllers

These controllers were used when the Laravel backend served Inertia.js pages.
The app is now a headless API; active endpoints live under:

- `app/Http/Controllers/Api/*`
- `app/Http/Controllers/Admin/*`
- `app/Http/Controllers/Client/*`
- `app/Http/Controllers/Provider/*`

These files are kept for reference only and are **not registered in any route file**.

Moved on 2026-06-02 during MVC audit cleanup.
